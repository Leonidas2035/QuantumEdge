2. ORDERBOOK AGGREGATOR — MATH & THRESHOLDS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Class: OrderBookAggregator (market_data/orderbook_aggregator.py)

Parameters:
  wall_threshold_btc = 20.0   (minimum BTC for a "whale wall")
  max_depth_pct      = 2.0    (scan range: ±2% from mid-price)

Detection Algorithm:
  For each side (BUY/SELL):
    1. Iterate levels from best price outward.
    2. Skip levels outside ±max_depth_pct.
    3. If single level qty ≥ wall_threshold_btc → wall detected.
    4. Otherwise, accumulate cumulative qty.
       If cumulative ≥ wall_threshold_btc → distributed wall detected.
    5. Return the CLOSEST wall (first one found).

Formula:
  wall_distance_pct = ((wall_price - current_price) / current_price) × 100

Output Keys:
  closest_bid_wall_btc       — Size of closest bid wall (BTC)
  closest_bid_wall_dist_pct  — Distance from mid-price (%, negative)
  closest_ask_wall_btc       — Size of closest ask wall (BTC)
  closest_ask_wall_dist_pct  — Distance from mid-price (%, positive)
