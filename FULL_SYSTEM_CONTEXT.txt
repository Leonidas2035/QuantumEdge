## 3. TECHNOLOGY STACK

| Layer | Technology | Notes |
|-------|-----------|-------|
| Language | Python 3.10+ | Strict typing, asyncio |
| WS Feeds | `websockets` | Binance Mainnet streams |
| IPC Bus | ZeroMQ (PUB/SUB) | Port 5555 (data), port 5557 (telemetry) |
| TSDB | QuestDB 8.x | ILP TCP :9009, REST :9000, WAL tables |
| LLM (Prod) | Gemini 2.5 Flash | via `google-genai` SDK v2 |
| LLM (Router) | Model Router | Multi-backend: Gemini / OpenAI / TRT-LLM |
| ML Hot Path | XGBoost | Signal / confidence / execution models |
| ML Inference | TensorRT-LLM | GPU-accelerated inference (GKE) |
| Execution | CCXT | Binance Futures Testnet |
| Container | Docker + docker-compose | Multi-stage builds |
| Orchestration | GKE (prod), docker-compose (dev) | Kubernetes for production |
| Logging | `structlog` (JSON) | Correlation IDs, latency tracking |
| Config | YAML + `.env` | `config/config.yaml`, env vars for secrets |

## 5. COMMANDS — HOW TO RUN

```bash
# Environment setup
cd /home/l_garnatko/QuantumEdge
source .venv/bin/activate
export PYTHONPATH=src   # CRITICAL: all imports use quantum_edge_core.*

# QuestDB schema initialization
python scripts/setup_questdb.py --host 127.0.0.1 --port 9000

# Start Hub (data collection)
PYTHONPATH=src python QuantumEdge.py run
# or directly:
PYTHONPATH=src python -m quantum_edge_core.market_data.hub

# Start Bot (shadow mode)
PYTHONPATH=src python src/quantum_edge_core/ai_scalper_bot/run_bot.py

# Diagnostic tools
PYTHONPATH=src python scripts/zmq_sniffer.py --port 5555 --duration 30
PYTHONPATH=src python scripts/test_supervisor_contracts.py

# QuestDB queries
curl "http://127.0.0.1:9000/exec?query=SELECT+count()+FROM+klines_1m"
curl "http://127.0.0.1:9000/exec?query=SELECT+count()+FROM+orderbook_snapshots"
```
