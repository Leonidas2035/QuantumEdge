# Огляд архітектури QuantumEdge

Цей документ містить короткий опис структури проєкту QuantumEdge після переходу на `src/` layout.

## 1. Meta-Agent: Оркестратор змін
Центральним елементом системи є **Meta-Agent** — контрольований оркестратор змін з інтегрованими шлюзами безпеки.

- **Призначення**: Сканування контексту проєкту, побудова промптів та створення структурованих наборів змін.
- **Локація**: `src/quantum_edge_infra/automation/meta_agent/`
- **Модель безпеки**:
  - Режим "тільки патчі" за замовчуванням.
  - Оцінка кожної зміни політикою безпеки.
  - Обов'язкове проходження перевірок у тіньових робочих просторах (shadow workspaces) та через quality gates.

## 2. Основні компоненти системи (Core Modules)
Проєкт організований за модульним принципом у директорії `src/`:

- **AI Scalper Bot (`src/quantum_edge_core/ai_scalper_bot/`)**: Основний торговий бот, що реалізує стратегії скальпінгу з використанням ML.
- **Supervisor Agent (`src/quantum_edge_core/supervisor/`)**: Система нагляду, яка моніторить стан ботів, керує ризиками та забезпечує дотримання політик.
- **Market Data Hub (`src/quantum_edge_core/market_data/`)**: Централізований вузол для збору та розповсюдження ринкових даних.
- **ML & Inference Engine (`src/quantum_edge_ml/`)**: Моделі машинного навчання та інфраструктура для TensorRT-LLM.

## 3. Структура репозиторію
- **`src/quantum_edge_core/`**: Основна бізнес-логіка (Market Data, Supervisor, Bots).
- **`src/quantum_edge_infra/`**: Інфраструктура, автоматизація (Meta-Agent) та спільні інструменти.
- **`src/quantum_edge_ml/`**: Моделі та інструменти машинного навчання.
- **`docs/`**: Детальна документація архітектури, операцій, безпеки та окремих модулів.
- **`tests/`**: Набір тестів для перевірки функціональності компонентів.
- **`config/`**: Загальні конфігураційні файли.
- **`QuantumEdge.py`**: Головний оркестратор для запуску всієї системи.

## 4. Швидкий старт та інструменти
Керування системою здійснюється через `QuantumEdge.py` або `meta_agent.py` (wrapper):
- `python QuantumEdge.py start` — запуск системи.
- `python meta_agent.py diag` — діагностика Meta-Agent.
- `python meta_agent.py ui` — запуск локального Центру Управління.
